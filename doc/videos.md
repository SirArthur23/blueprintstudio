# Screen-recording plan

Status: draft scripts, not recorded videos. Revise against persona simulations and the verified interface. Use fictional project data, the production preview, a clean browser profile, readable zoom, a visible cursor, and captions. Provide German and English versions or clearly label audio/caption languages. Do not show private browser tabs or notifications.

## 1. What Blueprint Studio helps you do — 90 seconds

Show the fictional project goal, full workflow, ownership, and final report. Explain: “Before building an AI workflow, decide what AI assists with and who controls its output.” Show EN/DE and the backup command. End with the concrete result: an agreed process map and report. Do not claim automated checks certify safety.

## 2. Your first blueprint — 4–6 minutes

Start blank. Enter a small-team training-document scenario, AI boundaries, sources, and operating settings. Generate a draft, inspect its assumptions, replace placeholder owners, and show the next-step button through the flow. Pause at the human approval point; ask viewers who should own it in their team.

## 3. Edit the canvas and governance — 3–5 minutes

Add a human task, connect it, label a revision branch, edit the owner, undo/redo, fit the workflow, and resize the inspector. Show the relationship between the matrix and canvas; these are editable planning records, not a running automation. Demonstrate a gate with a named human.

## 4. Checks and explainable alternatives — 3–5 minutes

Create an unsafe AI-to-output path. Show the trigger, missing control, repair, and check result. Explain when a documented exception is appropriate. Create a privacy-first alternative, read its changes, adopt it, and restore the previous blueprint snapshot. Make the regenerated-workflow behavior clear.

## 5. Save, share, and recover — 2–3 minutes

Export the JSON backup and Markdown report, preview print/PDF, reload, and import the backup. Show where privacy information lives. Explain: “This browser holds your work. A JSON backup is how you move it or recover it.” Mention that hosting can receive ordinary access logs and that exports contain the information entered.

## Publish after the interface is stable

Record a short pilot first and replay its demonstrated task against the relevant persona script. Real-user testing is deferred under the current budget; this replay is not audience validation. Correct unclear wording before recording the series. Add videos to the manual only once captions, language labels, links, and screen readability are verified.
