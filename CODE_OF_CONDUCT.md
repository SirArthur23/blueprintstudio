# Community conduct

Treat contributors and users with respect. Critique ideas and code clearly, allow questions at every experience level, and respect people's privacy and boundaries.

Harassment, discriminatory remarks, threats, doxxing, sexual advances, and repeated disruptive behavior are unacceptable. Do not publish another person's private project data or contact details.

Maintainers may edit or remove inappropriate contributions, restrict participation, or ban accounts for serious or repeated violations. Decisions should be proportionate and explain the behavior involved.

Send community feedback or conduct concerns privately to [blueprintstudio@schmidtpabst.com](mailto:blueprintstudio@schmidtpabst.com). Arthur Schmidt-Pabst is the responsible maintainer. Include the relevant behavior and context without private project data. No response-time promise is made. Security vulnerabilities should use the GitHub private reporting route in [SECURITY.md](SECURITY.md), not public discussion.
