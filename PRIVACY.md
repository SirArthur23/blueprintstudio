# Privacy / Datenschutz

## English

Blueprint Studio stores the current blueprint, saved alternatives, chosen language, and inspector width in your browser's local storage. The app does not upload blueprint content, call AI APIs, use analytics, create accounts, or synchronize projects. Fonts are bundled with the app.

Opening a hosted copy still sends ordinary requests for HTML, scripts, styles, and fonts to its host. The host may receive IP addresses and ordinary access-log metadata. The public operator, logging retention, contact route, and applicable site notices must be documented before launch. This document describes application behavior; it does not promise that a future hosting provider keeps no logs.

Local storage is not encrypted by Blueprint Studio. Access to your browser profile, extensions, and other scripts on the same origin can expose it. Apps under `ai.schmidtpabst.com` share an origin even if they use different paths. Use descriptions of data sources rather than pasting real confidential records into a planning tool.

Exported JSON, Markdown, clipboard content, and printed reports contain the information you entered. You control where you save or share them. Export a JSON backup regularly: clearing site data, private-browsing sessions, storage limits, and device changes can remove or hide local work. The app reports storage failures; it cannot guarantee recovery without a backup.

There is one current project per browser/origin. Starting blank or loading Demo replaces it after confirmation. Alternative adoption saves the previous workflow/settings as a restorable snapshot. To erase stored data, use your browser's site-data controls; this may also affect other apps on the same origin.

## Deutsch

Blueprint Studio speichert den aktuellen Blueprint, Alternativen, Sprache und Inspektorbreite im lokalen Speicher Ihres Browsers. Die Anwendung lädt keine Projektinhalte hoch, ruft keine KI-API auf und verwendet keine Analysewerkzeuge, Konten oder Synchronisierung. Schriftarten werden mitgeliefert.

Beim Aufruf einer gehosteten Version werden HTML, Skripte, Stile und Schriftarten vom Server angefordert. Der Betreiber kann IP-Adressen und gewöhnliche Zugriffsmetadaten erhalten. Betreiberangaben, Aufbewahrung von Zugriffsprotokollen, Kontaktweg und erforderliche Website-Hinweise werden vor der Veröffentlichung festgelegt.

Der lokale Browserspeicher wird von der Anwendung nicht verschlüsselt. Browserprofile, Erweiterungen und andere Skripte derselben Origin können darauf zugreifen. Anwendungen unter `ai.schmidtpabst.com` teilen diese Origin auch bei unterschiedlichen URL-Pfaden. Beschreiben Sie Quellen; verwenden Sie für die Planung keine vertraulichen Originaldatensätze.

JSON-, Markdown-, Zwischenablage- und Druckausgaben enthalten Ihre Eingaben. Sie entscheiden über Speicherung und Weitergabe. Exportieren Sie regelmäßig eine JSON-Sicherung: gelöschte Website-Daten, privates Browsen, Speicherlimits und Gerätewechsel können lokale Arbeit entfernen oder unzugänglich machen.

Pro Browser/Origin gibt es ein aktuelles Projekt. Leerstart und Demo ersetzen es nach Bestätigung. Die Übernahme einer Alternative bewahrt den vorherigen Workflow und seine Einstellungen als wiederherstellbaren Stand. Über die Website-Daten-Verwaltung Ihres Browsers können Sie gespeicherte Daten löschen; andere Anwendungen derselben Origin können davon ebenfalls betroffen sein.
